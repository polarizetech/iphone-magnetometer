# Artifact and control checklist

Before interpreting a session, record pass/fail with evidence for every item.

- [ ] Phone remained fixed; no figure-eight or handling occurred
- [ ] Magnetic case, watch, charger, motors, speakers, and moving metal controlled
- [ ] Achieved cadence and sample-interval histogram reviewed
- [ ] Quantization/repeated-value behavior reviewed
- [ ] Accelerometer and gyroscope thresholds preregistered
- [ ] Rejected beats and reasons reported
- [ ] Magnetometer morphology absent from inertial channels
- [ ] Camera/flash on-vs-off electronic artifact considered
- [ ] ≥1,000 shuffled-interbeat surrogates run
- [ ] ≥1,000 circular-time-shift surrogates run
- [ ] Four channels and lag-search multiplicity corrected
- [ ] Odd/even and first/second-half agreement reviewed
- [ ] Frozen template scored only on untouched held-out beats
- [ ] Time-reversed, wrong-distance, and shuffled templates fail
- [ ] 0–500 ms timing-jitter curve reported
- [ ] Prior-information level comparison reported
- [ ] 5/7.5/15/30 cm trend reported without hard-coded exponent
- [ ] Empty-room control absent or substantially reduced
- [ ] Independent day/session replication completed
- [ ] Synthetic injection sensitivity bound established for this phone/noise block
- [ ] Conclusion uses neutral heartbeat-correlation language
